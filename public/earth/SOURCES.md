# Earth texture sources

These web-optimized textures are derived from official NASA imagery.

- `earth-day.webp` — NASA Visible Earth, August Blue Marble Next Generation with topography and bathymetry (August 2004).
  Source: https://eoimages.gsfc.nasa.gov/images/imagerecords/73000/73776/world.topo.bathy.200408.3x5400x2700.jpg
- `earth-night.webp` — NASA Earth Observatory / Black Marble, 2016 global night lights.
  Source: https://assets.science.nasa.gov/content/dam/science/esd/eo/images/imagerecords/144000/144898/BlackMarble_2016_01deg.jpg
- `earth-clouds.webp` — NASA Visible Earth, Blue Marble cloud mosaic.
  Source: https://eoimages.gsfc.nasa.gov/images/imagerecords/57000/57747/cloud_combined_2048.jpg

The originals are not committed; only web-optimized derivatives are stored in this repository.
